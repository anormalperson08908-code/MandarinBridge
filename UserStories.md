# User Stories

**Overview:** This document contains user stories for the International Student Chinese Immersion Learning Platform – MandarinBridge.

# 1
As a beginner student, I want to learn basic Chinese vocabular. 
So that I can start simple conversations in daily life.

# 2
As a beginner student, I want to learn basic Chinese vocabulary
So that I can start simple conversations in daily life.

# 3
As a student, I want personalized learning paths
So that I can learn Chinese at my own pace and level.

# 4
As a learner, I want quizzes and tests
So that I can evaluate my understanding of the material.

# 5
As a user, I want a progress tracking system
So that I can monitor my improvement over time.

# 6
As an international student, I want to learn about Chinese culture
So that I can better understand real-life contexts and communication.

# 7
As a user, I want pronunciation feedback
So that I can correct my speaking mistakes.

# 8 
As a user, I want mobile access to the platform
So that I can learn anytime and anywhere.

**Notes:** 
-These user stories will guide feature development.
-They are prioritized using the MoSCoW method in a separate document.
